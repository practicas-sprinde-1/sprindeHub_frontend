# Preferencias de estilos

- Al crear o editar archivos CSS, no añadir reglas `@media` salvo que se solicite expresamente.

## Organización del código

- Para funcionalidades equivalentes, reutilizar la misma estructura y los mismos nombres de clases.
- En JavaScript, usar nombres descriptivos y preferir funciones y pasos explícitos a soluciones compactas difíciles de seguir.
- Se pueden usar `map`, `find` y `filter` cuando hagan el código más claro.
- Los modales deben seguir este orden: overlay, sección modal, título, cierre, contenido y acciones.
